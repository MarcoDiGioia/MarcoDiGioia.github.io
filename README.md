# marcodigioia.github.io

Pagine statiche dei progetti (privacy policy delle app, ecc.). Pubblicate con GitHub Pages da `main`.

- `luna/privacy/` — Luna
- `prendimi/privacy/` — Prendimi
- `scadi/privacy/` — Scadì
- `billy/privacy/` — Billy

Ogni progetto nuovo ha la sua cartella.

Sito dello sviluppatore (home, `progetti/`, una pagina per progetto, versione inglese in `en/`):

- `index.html`, `progetti/`, `leap/`, `pomona/`, `scadi/`, `luna/`, `billy/`, `pothole-patrol/` e le versioni in `en/`
- `assets/` — stili e script condivisi
- `privacy/` — elenco delle privacy policy delle app

PomonaLinux grows well on your Mac.

Makes the hardware of the 2016–2017 MacBook Pro with Touch Bar work on Linux and tells you what works and what it fixed. App plus modular command line. It never touches macOS or the firmware.

What it fixes

On these Macs Linux usually leaves four things half done. Each module is optional and only offers what your Mac needs.

On these Macs, Linux usually…What Pomona does
⌨️ Touch Bar, camera and light sensorStay dead: they sit behind Apple's T1 chip, which Linux never starts.Starts the T1 at every boot from the firmware macOS keeps on the EFI partition. You get Esc, F1–F12 and special keys, a camera any video-call app can use, and automatic brightness.
📶 Wi-Fi (Broadcom BCM43602)Sees networks but rejects every connection.One click installs the board file the card needs (downloaded when you run the fix, after you agree). Every changed file is backed up and the fix can be undone.
🔊 Audio (Cirrus Logic CS8409)Silent speakers: the kernel driver does not know the Mac's amplifiers.Builds the community Mac driver with DKMS, from the exact source of your kernel, and rebuilds it at every kernel update.
😴 SleepThe Mac hangs when it goes to sleep and never wakes up.Reads the system journal to find boots that ended asleep and can turn suspend off, and back on.

Know what actually works

Pomona does not just apply fixes, it records them. The Report page runs every module's checks and writes a compatibility certificate. You can share it to grow the compatibility table. Nothing is sent unless you press Submit on GitHub, and nothing in a certificate identifies you or your Mac.

Installation

On Ubuntu, Mint, Pop!_OS, Zorin, elementary, Debian: download the .deb from the latest release and install it from the same folder.

$ sudo apt install ./pomona_*_amd64.deb
  • A 2016–2017 MacBook Pro with Touch Bar.
  • macOS still installed, or at least its EFI partition left as it was.
  • Kernel 6.15+ for the Touch Bar. The Wi-Fi fix needs a temporary connection, once.

Every change can be undone

A backup of every touched file, reversible fixes, no black boxes.

  • Independent, optional modules
